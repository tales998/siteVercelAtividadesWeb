utilizando grid

display: grid
é uma propriedade que divide o layout em grade(colunas e linhas)

grid-template-columns
Define quantas colunas existem e a largura de cada uma.

grid-template-rows
Define o tamanho das linhas no layout

gap
Espaçamento entre os blocos, sem precisar usar margin.

grid-template-areas
Define como exibir colunas e linhas, usando nomes para as áreas da grade.
